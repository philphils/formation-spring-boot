## Spring-Boot : Le couteau suisse
## du développement Java

- On a vu que Spring-Boot est un outil très complet
- Permet de couvrir la plupart des besoins d'un projet
- Permet de se concentrer sur le métier et de se concentrer sur la qualité du code

--

## Une dépendance trop forte ?

- Une question se pose : avec Spring-Boot, la dépendence à Spring est-elle trop forte ?
- Une politique de support à long terme à surveiller...
- Mais on gagne indéniablement en productivité et en qualité de code
